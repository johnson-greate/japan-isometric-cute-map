# 🗻 日本地理・立體可愛地圖（Japan Isometric Cute Map）

專為**大學一年級日本地理課程**設計的互動式立體可愛日本地圖，以 **Isometric 2.5D 等軸測立體積木＋和風粉彩繪本風格** 呈現全日本 **47 個都道府縣**（1 都、1 道、2 府、43 縣）。

## ✨ 功能特色

- **🎨 Isometric 2.5D 立體積木地圖**：基於真實日本列島邊界（Albers 投影＋13.5° 等軸測傾角擠出），滑鼠懸停與點選時都道府縣積木立體浮起。
- **🌺 沖繩諸島互動 3D 小插圖**：於日本海側以可愛等軸測木框呈現沖繩縣，完整支援點擊、圖釘彈跳、人口／GDP 3D 凸起與測驗作答。
- **📌 47 個縣廳所在地立體圖釘**：全部行政中心均於真實地理座標插上彩色亮面圖釘，並標示大一必考的 **18 個縣名與縣廳名稱不同的異名縣廳**；關東、關西、瀨戶內高密度區附有海上快捷導引標籤。
- **📊 最新官方數據**：完整收錄正名、日文假名讀音、舊令制國名、官方人口（總務省統計局「人口推計」2024.10）、官方縣內總生產 GDP（內閣府「縣民經濟計算」最新確報）與人均 GDP。
- **🌋 兩大地理經典主題線**：一鍵切換 **糸魚川—靜岡構造線（大地溝帶西緣）** 與 **太平洋工業帶（東海道—山陽大動脈）**。
- **🎯 大一地理隨堂小測驗**：支援「綜合題」「異名縣廳專攻」「地方分區」「地圖直接點選」4 種互動測驗模式。
- **📚 47 都道府縣速查表**：支援搜尋正名、縣廳、日文讀音或舊令制國名，按 GDP／人口／由北至南排序並一鍵定位。

## 🚀 本地啟動方式

純前端零依賴靜態網頁，直接以瀏覽器打開 `index.html` 即可離線使用；或於專案目錄執行：

```bash
python3 -m http.server 8000
```

## 📂 專案結構

- `index.html` — 主頁面與互動介面
- `styles.css` — 可愛和風粉彩繪本視覺樣式
- `app.js` — 2.5D Isometric SVG 渲染、圖釘互動、地質線／工業帶與測驗系統
- `data/prefectures.js` — 47 都道府縣官方人口、GDP、縣廳與地理教學筆記
- `data/japan-geo.js` — 等軸測投影簡化幾何邊界與沖繩互動插圖資料
